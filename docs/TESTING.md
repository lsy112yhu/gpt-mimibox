# 验证记录

## 自动测试

`npm test`：6 项 Node 测试 + 10 项 Python 测试，全通过。

- 中文自然语言候选与同义词匹配。
- 分类/包/动静图/场景/标签组合筛选。
- 无结果、结果数限制、未知 ID。
- 随机避免近期重复、空池和耗尽回退。
- 分类统计、绝对图片 URL。
- 真实 Node MCP 子进程 initialize、通知、tools/list、tools/call 和无效参数错误。
- 未审核包隔离；明确审核证据要求。
- 增量导入及重复图片多来源合并。
- 损坏图片、伪装 SVG、符号链接路径逃逸。
- ZIP Slip 和 ZIP 符号链接拒绝。
- 动画原图保持两帧与内容校验。
- 语义 SHA/身份不匹配拒绝。
- 上游删除文件后的库存更新和无引用媒体清理。
- 备份只更新已存在记录元数据，不把本地隐藏当删除仓库。

`python scripts/mimibox.py validate`：604 张原图及全部缩略图解码成功；ID/hash 不重复；尺寸、格式、帧数、大小匹配；来源、许可、路径及分类完整。原图逐帧解码不是只检查文件扩展名。

## 网页实测

Chromium 云浏览器实际打开预览，确认首页图片加载、搜索结果、详情原图和许可证可见。同时验证收藏后列表立即更新、刷新后 IndexedDB 收藏保留；随机按钮打开真实图片详情；管理页显示备份和恢复路径。

390×844 手机 iframe（375px 内容宽度）和 768×1000 平板 iframe（753px 内容宽度）的 `scrollWidth == clientWidth`，无横向溢出。桌面截图检查首屏图片、排版与筛选。非真实手机/平板设备。
