# 版权与审核策略

软件源代码采用 MIT。图片、首帧缩略图及第三方描述遵循各自来源许可，详见数据记录和 upstream 证据文件。

1. 新包默认待审核。未知授权不进入 `public/`、已审核目录或发布归档。
2. 手工 `--approved --evidence ...` 是维护者的明确审核动作，不根据许可证名字自动放行。
3. 许可通过意味着有可追溯的分发许可声明，不宣称已独立取得每个动漫角色或截图的原始权利人授权。争议素材应撤下并联系权利人。
4. 原始图片保持字节不变；缩略图为尺寸调整、首帧提取和 WebP 转换。语义描述去除模板前缀、标题使用可见文字/标签，均保留上游署名与许可。
5. CC BY-NC-SA 部分的修改/衍生内容继续按该许可提供，标明修改；不得拿软件 MIT 覆盖素材许可。seio 素材限非商业，并保留失效药片、camera-2018、anka 署名。
6. 浏览器上传不自动获准公开。备份中的 `status` 字段不能绕过审核；同步脚本将新增图片放入忽略目录。
7. 用户于 2026-10-25 明确授权「允许公开上传」，因此本仓库的源码及已审核素材可上传至公开 GitHub 仓库 `lsy112yhu/gpt-mimibox`。该授权不改变素材本身的非商业、署名及相同方式共享等许可条件，也不适用于未来未知授权素材。Sites 网站继续保持 owner-only。

移除请求请提供图片 ID、来源及权利说明。永久下架需移除全部来源、重新构建并部署；如果已经公开传播，单纯删除 Git 工作树不能清除第三方副本。
